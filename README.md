Задание №1. Замена символов в строках списка.
Условие задачи
Дан список строк и два символа: старый и новый. Требуется написать функцию replace_characters(lst, old, new), которая заменяет все вхождения старого символа на новый в каждой строке списка.

Задание №2. Подсчет определенных символов.
Условие задачи
Напишите функцию count_char(lst, char), которая подсчитывает, сколько раз символ char встречается в каждом элементе списка строк.

Задание №3. Сжатие строки
Условие задачи
Дана строка, состоящая из символов. Требуется написать функцию compress_string(strk), которая сжимает строку таким образом, что каждая группа подряд идущих одинаковых символов заменяется на этот символ и количество его повторений.

Задание №4. Пересечение нескольких множеств
Условие задачи
Напишите функцию sets_intersection(*sets), которая возвращает множество элементов, которые встречаются во всех переданных множествах.

Задание №5. Фильтрация словаря по значению
Условие задачи
Реализуйте функцию filter_dict_by_value(d, threshold), которая принимает на вход словарь d и число threshold, и возвращает новый словарь, содержащий только те пары ключ-значение, у которых значение строго больше указанного порога threshold.

Задание №6. Преобразование DNA в RNA
Условие задачи
ДНК и РНК — это последовательности нуклеотидов. Требуется написать функцию to_rna(dna), которая принимает на вход цепь ДНК и возвращает соответствующую цепь РНК (транскрипция РНК) по правилам замены:
- G → C
- C → G
- T → A
- A → U

Задание №7. Проверка палиндрома
Условие задачи
Дана строка. Создайте функцию is_palindrome(strk), которая проверяет, является ли данная строка палиндромом (читается одинаково слева направо и справа налево).

Задание №8. Поворот матрицы
Условие задачи
Дана квадратная матрица N × N. Требуется написать функцию rotate(mat), которая поворачивает матрицу на 90 градусов по часовой стрелке и возвращает новую матрицу.
